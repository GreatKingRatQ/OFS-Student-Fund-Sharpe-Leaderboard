How the Sharpe ratio is worked out

Each member's sub-account value is taken at every close from Interactive Brokers. Daily returns strip out deposits and withdrawals, so new money never counts as a gain.

Sharpe = average daily return above the risk-free rate, divided by the standard deviation of those daily excess returns, times √252 to put it in annual terms.

Read it with care

With only a few weeks of history, one good or bad day moves the ratio a lot. Volatility is annualised; return and drawdown cover the period chosen above. Only return statistics are shown here, never balances or account numbers.
